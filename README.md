This is a simple map maker for DND. You can use it as it, or you can fork it and make your own version. I don't care.

I'm making it for a school dnd club, and I wanted to make it easy for people to create maps for their campaigns.

STLs for the 3D printed frame and pins are included in the repository. You can print them out and use them to create a physical version of your map.
For the frame, use TPU 95A for best results. For the pins, use PLA or PETG.
Reason on the materials is that the TPU provides some extra flex, making inserting pins significatly easier.
