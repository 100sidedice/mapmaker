Tiles

| This is a map maker for a 3d-printed dungeon tile system. You can get the stls using the Download STLs button below.
| keybinds: q/e to cycle tile type, Middle-click to move, 1-9 for brush size, f to fill, ctrl for eyedropper, alt to select, ctrl+s to save, s to select area, o to outline
| each grid cell (8x8 tiles) = 1 peice of paper
| How to use: 3d-print mats in tpu 95A, pins in PLA. 2d-print the map. Cut them out, align on mat, use spiral pin to peirce paper, place normal pin to hold.
